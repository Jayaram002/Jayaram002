## Featured Projects

### [Traffix NeuraX 3.0](https://github.com/Jayaram002/Traffix)

**AI-powered urban traffic intelligence and decision-support platform.**

- Built with **Python, FastAPI, PostgreSQL, SQLAlchemy, Scikit-learn, NetworkX, Pandas, NumPy, and Google Gemini**
- Includes congestion-state estimation, incident detection, multi-horizon traffic forecasting, and capacity-aware routing
- Provides role-based portals for operators, emergency services, planners, and commuters
- Demonstrates REST API design, machine learning evaluation, graph algorithms, authentication, RBAC, audit logging, and database integration
- Uses a Hyderabad-scale road-network simulation with forecasting, robustness testing, and emergency corridor workflows

### [AeroShield AI — SIH26188](https://github.com/Jayaram002/SIH26188)

**Full-stack airport identity and document screening prototype for explainable security decisions.**

- Built with **React, Vite, TypeScript, FastAPI, PostgreSQL, Supabase, SQLAlchemy, Alembic, Pytest, and Docker**
- Includes document OCR and validation workflows, simulated biometric verification, risk scoring, red-flag alerts, and audit logging
- Implements JWT authentication, role-based access control, password hashing, file validation, rate limiting, and data masking
- Includes separate frontend and backend applications with API documentation and demo scenarios
- Developed as a **Smart India Hackathon 2026** project prototype
- [Live demo](https://sih-26188-three.vercel.app/login)

> **Note:** AeroShield AI is a demonstration prototype. Its biometric services use simulated/demo adapters and are not connected to real government, airport, or biometric databases.

### [SkillGraph — Wexa](https://github.com/Jayaram002/Wexa)

**Java and Spring Boot career recommendation application using graph-based skill and job relationships.**

- Built with **Java, Spring Boot 3, Java 21, CognoDB, openCypher, Neo4j Bolt Driver, Thymeleaf, HTML, CSS, and JavaScript**
- Models users, skills, jobs, companies, and technologies as connected graph entities
- Provides candidate skill profiles, job recommendations, skill-gap analysis, learning paths, and graph visualization
- Demonstrates multi-hop graph traversal, backend service design, Cypher queries, and graceful database fallback behavior
